# Weiß Schwarz 伤害模拟计算器 v2.0

基于 HTML/CSS/JavaScript 的单页 Web 应用，用于模拟 Weiß Schwarz 卡牌游戏的伤害概率分布。

## 功能特性

### 🎲 核心模拟
- 支持 100,000 次蒙特卡洛模拟
- 异步批量处理，UI 不卡顿
- 实时进度条显示

### 📊 伤害序列语法
- **基本伤害**：`1,2,3` — 连续造成指定点数的伤害
- **反洗 (fx)**：`fx4` — 从休息室洗回 N 张非高潮卡
- **取消追加 (zj)**：`2zj(3)` — 若伤害被高潮卡取消，则追加后续效果
- **传火追加 (\*zj)**：`*2zj(2),3,4` — 取消后追加并将效果传递给下一个伤害
- **嵌套追加**：`4zj(3,fx4,2zj(2))` — 支持任意嵌套
- **卡片移动**：`DT>RS3`, `DT>CL`, `RS>DT2` — 在区域间移动卡片
- **条件判断**：`DT>RS4:C+zj(2)` — 根据移动结果触发追加效果
- **卡片操作**：`DT+C`, `CL-N`, `RS+N` — 在指定区域添加/移除卡片

### 📈 可视化
- Chart.js 概率分布柱状图（深色主题）
- 统计卡片（期望伤害、平均洗牌、平均升级）
- 详细概率表
- 多配置对比折线图

### 💾 配置管理
- 保存/加载模拟配置（localStorage）
- 配置列表浏览、查看详情、删除
- 一键载入配置到模拟器

### ⚖️ 对比分析
- 选择多个已保存配置进行对比
- 概率分布曲线叠加图
- 统计指标并排对比表

### 📥 数据导出
- 导出当前结果为 CSV
- 导出所有已保存配置为 CSV
- UTF-8 BOM 编码，Excel 直接打开

### 📱 响应式设计
- 手机 / 平板 / 桌面全适配
- 触屏友好
- 深色主题，护眼舒适

## 使用方法

1. 用任意现代浏览器打开 `index.html` 或访问https://nofameway.github.io/WS-DamageSim/
2. 在「模拟器」标签页输入牌组参数和伤害序列
3. 点击「⚡ 开始模拟」查看结果
4. 点击「💾 保存」存储当前配置
5. 切换到「⚖️ 对比」标签页进行多配置对比
6. 点击「📥 导出CSV」下载数据

### 伤害序列示例

| 描述 | 序列 |
|------|------|
| 基础连击 | `1,2,3` |
| 取消追加 | `2zj(3),4` |
| 反洗操作 | `1,fx4,3` |
| 传火追加 | `*2zj(2),3,4` |
| 传火叠加 | `*2zj(1),*3zj(2),4` |
| 嵌套追加 | `4zj(3,fx4,2zj(2))` |
| 卡片移动 | `DT>CL,DT>RS2,CL>RS` |
| 条件判断 | `DT>RS4:C+zj(2)` |

## 技术架构

```
index.html    — HTML 结构 + 内嵌 CSS（深色主题）
script.js     — 模块化 JavaScript
  ├── Utils       — 工具函数（shuffle, mean, std）
  ├── Parser      — 伤害序列解析器
  ├── Simulator   — 蒙特卡洛模拟引擎
  ├── Charts      — Chart.js 图表管理
  ├── Storage     — localStorage 持久化
  ├── UI          — Toast / Modal / 标签页
  └── App         — 主控逻辑
```
