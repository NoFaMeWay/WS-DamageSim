伤害序列语法参考

基本伤害操作

基本伤害：纯数字表示几点伤害

1,2,3 → 依次造成 1点、2点、3点伤害

反洗 (fx)：从休息室随机洗回指定数量的非高潮卡到牌组

fx4 → 从休息室随机洗回4张非高潮卡

取消追加 (zj)：若当前伤害被高潮卡取消，则执行括号内的追加效果

2zj(3) → 2点伤害，若被取消则追加3点伤害 4zj(3,fx4,2) → 4点伤害若取消，追加3点伤害、反洗4张、再2点伤害
传火追加 (*zj)

若当前伤害被高潮卡取消，则执行追加效果，并使下一个伤害也获得相同效果

*2zj(2),3,4 → 2点若取消：追加2点 + 下一个伤害也获得此效果 *2zj(1),*3zj(2),4 → 多个传火效果可叠加
卡片移动操作

格式：源位置>目标位置[数量]

位置代码：DT=牌组顶部 DB=牌组底部 RS=休息室 CL=计时区 HD=手牌

DT>RS3 → 从牌组顶部移3张到休息室 DT>CL → 从牌组顶部移1张到计时区（1点伤害） RS>DT2 → 从休息室移2张到牌组顶部
条件判断操作

格式：移动操作:条件+zj(追加内容)

条件：C=高潮卡 N=普通卡

DT>RS4:C+zj(2) → 从牌组顶移4张到休息室，若含高潮卡则追加2点伤害 DT>CL3:N+zj(1,fx2) → 从牌组顶移3张到计时区，若含普通卡则追加1点伤害+反洗2张
卡片添加/移除

格式：位置+/-卡片类型

DT+C → 牌组顶部添加一张高潮卡 CL-N → 计时区移除一张普通卡 RS+N → 休息室添加一张普通卡
